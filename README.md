# FitGirl Power Pack

A userscript that adds a dark theme and browsing tools to FitGirl Repacks.

## Install

1. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/).
2. Install the script from [Greasy Fork](https://greasyfork.org/en/scripts/541076-fitgirl-power-pack). Updates arrive automatically from there.

## Features

- **Dark theme:** applied before the page draws, using the site's own images recolored in the browser.
- **Tag filter:** on post lists, show only games with chosen tags or hide games with others. The list comes from the site's current tags, and filters clear when a new page loads.
- **Infinite scroll:** more posts load as you scroll, replacing the page number bar.
- **YouTube trailer buttons:** open a game's trailer in a popup.
- **Hidden comments:** comments stay behind a Show Comments button until you open them.
- **Tags page:** every tag on the site, at `/tags`, with a link in the top menu.
- **Right sidebar on every page:** at the same size as on the main page.
- **Back to top button:** appears once you've scrolled down.
- **Hide options:** optionally hide Uncategorized, Updates Digest or Hypervisor Bypass posts on the main page.

## Settings

Click **Settings** in the site's top menu, or open the Tampermonkey menu on any page of the site, to turn each feature on or off. The three hide options start off, and everything else starts on.

The Refresh tags button in the Settings panel updates the filter's saved tag list. It also refreshes by itself once a day.
